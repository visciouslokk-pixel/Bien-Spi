# Bien SPI

Interface métier EDL et DIA pour Grist, adaptée aux tablettes et à la charte graphique de la Métropole de Lyon.

Les dossiers, photos, signatures et référentiels métier restent dans le document Grist privé. Ce dépôt héberge uniquement l’interface et ses sources sans données métier.

## Utilisation

Ouvrir Bien SPI depuis Grist. La page publique seule ne donne accès à aucun dossier.

## Sources et reprise sur Forge

L’archive `bien-spi-grist-sources.zip` contient les sources nécessaires pour reconstruire l’interface : `npm install`, `npm test`, `npm run build`. Le dossier produit peut être hébergé sur Forge, puis son adresse renseignée dans le widget Grist. Aucun secret ni clé API permanente n’est nécessaire.

La recette sur les tablettes du service reste à réaliser avant généralisation.
