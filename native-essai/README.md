# Bien SPI — export natif — espace d’essai
Composant personnalisé de lecture des tables et pièces jointes Grist, réutilisant le modèle PDF existant. Ce dossier contient uniquement du code et les ressources graphiques. Aucun dossier métier, référentiel interne, photo, signature ou clé n’est hébergé ici.
Cette version est réservée à la recette sur un document Grist séparé. Elle ne remplace pas l’application publiée à la racine du dépôt. Les essais éditeur et tablette ainsi que le PDF avec pièce jointe native restent à valider.
